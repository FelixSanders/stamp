# Museum Stamp Collection Website

Open `index.html` in a browser.

The site uses the 21 stamp sheets from the supplied PDF as its image archive. Each sheet has clickable hotspots and each hotspot opens the museum information panel.

To change museum details or hotspot positions, edit `script.js`:
- `museumInfo` contains the museum names, locations, types, and descriptions.
- `stamps` contains the clickable hotspot positions for each sheet.
- Hotspot coordinates are percentages of the sheet image.

The PDF supplied for this project contains image scans rather than machine-readable museum metadata, so the museum information included in the prototype is a starting point and can be customized with your own verified details.
